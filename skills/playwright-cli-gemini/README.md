# playwright-cli skill for Gemini CLI (corporate)

A self-contained Agent Skill for Gemini CLI. It adds proxy, internal-registry, SSO and
data-handling guidance on top of `playwright-cli`. It is not generated by `scripts/update.js`.

## Install

Workspace (shared via the repo) or user scope:

```bash
mkdir -p .gemini/skills && cp -r skills/playwright-cli-gemini .gemini/skills/
# or for all projects
mkdir -p ~/.gemini/skills && cp -r skills/playwright-cli-gemini ~/.gemini/skills/
```

Alternatively `gemini skills install <path-or-git-url>`. Then run `/skills reload` in Gemini CLI
and check `/skills list`.

## Notes for admins

- Gemini CLI skills do not support `allowed-tools`. To avoid a prompt per command, allow the shell
  prefix in your Gemini policy / settings (for example the `playwright-cli` command) rather than
  broad shell access.
- Distribute proxy and browser settings through `.playwright/cli.config.json` or `PLAYWRIGHT_MCP_*`
  environment variables.
